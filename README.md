# VideoToQuiz AI (videotoquiz.com)

Transform any YouTube video into interactive study quizzes, multiple-choice tests, and structured flashcards in seconds using AI.

## 🚀 Features

- **Instant YouTube Transcription**: Fetches English captions and transcripts directly from YouTube videos.
- **AI-Powered Quiz Generation**: Structured multiple-choice questions with answer keys, explanations, and difficulty ratings.
- **Bilingual & Responsive Interface**: Modern academic dark aesthetic with seamless English / Chinese UI switching.
- **Google OAuth & Credit System**: Secure Google One Tap / OAuth authentication with user credit quota management.
- **Tiered Monetization**: Seamless Creem & PayPal integration with One-Time credit top-ups and Pro membership subscriptions.
- **Enterprise-Grade SEO & GEO**: Complete SSR metadata, OpenGraph, JSON-LD Schema (SoftwareApplication, FAQPage), and canonical URLs.

## 🛠️ Tech Stack

- **Framework**: Next.js 15 (App Router)
- **Styling**: Tailwind CSS
- **AI Engine**: DeepSeek V3 API
- **Deployment**: Vercel
- **Authentication**: Google OAuth 2.0
- **Payments**: Creem + PayPal

## 📦 Getting Started

### Prerequisites

- Node.js 18+
- pnpm

### Installation

```bash
pnpm install
```

### Local Development

```bash
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser.
